# Seventh Floor — Torreguadiaro, Sotogrande

Static sales website for a 130 m² three-bedroom beachfront apartment on the seventh floor in Torreguadiaro (Sotogrande, Cádiz).

- `index.html`, `styles.css`, `main.js` — the page
- `scrub/` — silent 720p/24fps clips with a 12-frame keyframe interval, scrubbed by scroll position
- `video/` — 720p walk-throughs with sound (opened from "Watch with sound")
- `img/` — poster frames and Open Graph image
- `vercel.json` — clean URLs and long cache headers for media

Deployed on Vercel. Push to `main` to redeploy.
